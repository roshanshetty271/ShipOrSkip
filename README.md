# ShipOrSkip 🚀

**Validate your ideas before you build.**

ShipOrSkip is an AI-powered idea validation platform that helps builders, indie hackers, and entrepreneurs quickly assess whether their project idea is worth pursuing — before investing weeks building something that already exists.

> *"Should I ship it or skip it?"*

## What It Does

Describe your project idea in plain English, and ShipOrSkip delivers:

- **Competitive Landscape** — Discovers similar products, side projects, and open-source repos across the web
- **Pros & Cons Analysis** — Honest assessment of your idea's strengths and weaknesses
- **Market Gap Identification** — Finds opportunities your competitors are missing
- **Actionable Build Plan** — Concrete next steps, tech stack suggestions, and differentiation strategies
- **Ship or Skip Verdict** — A clear recommendation backed by data

## Two Analysis Modes

### ⚡ Fast Analysis
Quick validation powered by AI web search and GPT synthesis.

### 🔬 Deep Research
Comprehensive multi-source competitive intelligence across web search, GitHub, and product databases. Streams real-time progress as the AI researches your idea.

## Built With

- **Next.js 14** — React framework with App Router
- **FastAPI** — High-performance async Python API
- **OpenAI GPT-4.1 mini and GPT-4.1 nano** — mini runs the analysis, nano answers follow-up chat
- **Tavily Search** — Real-time web search optimized for AI agents
- **Supabase** — PostgreSQL database with authentication
- **Tailwind CSS** — Utility-first styling

## Who It's For

- 🛠️ **Indie hackers** evaluating weekend project ideas
- 🚀 **Startup founders** validating concepts before committing resources
- 🎓 **CS students** choosing portfolio projects that stand out
- ⏱️ **Hackathon participants** quickly assessing viability under time pressure
